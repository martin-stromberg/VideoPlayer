# Drehbuch 02 — „Gleich geht's weiter mit eurem Programm" (Programmhinweis)

**Ziel-Datei:** `clips/funki-programmhinweis.mp4` — ca. 15 s, 1280×720, 25 fps
**Einsatz:** Allgemeiner Lückenfüller zwischen zwei Sendungen.

## Szene

Funki steht links und deutet auf eine Texttafel rechts — wie ein Ansager vor der Wandkarte.

| Zeit | Bild | Ton |
|------|------|-----|
| 0–1,5 s | Funki schwebt von links herein, bleibt links stehen, leuchtet ruhig. | leiser Einsteigs-Ton |
| 1,5–4 s | Auf der rechten Seite erscheint Buchstabe für Buchstabe: **„Gleich geht's weiter"** — Funki zeigt mit dem Arm dorthin. | Tipp-Tick pro Zeichen (sehr leise) |
| 4–8 s | Zweite Zeile tippt sich ein: **„mit eurem Programm"** — Funki nickt zufrieden (Kolben wippt). | Tipp-Tick |
| 8–13 s | Funki strahlt kurz heller auf, unter der Tafel läuft ein kleiner Fortschrittsstrich („Läuft…"). | warmer Dauerton |
| 13–15 s | Beides blendet sanft aus, Funki winkt zum Abschied. | Jingle-Ausklang |

## Texte

- „Gleich geht's weiter"
- „mit eurem Programm"
- „…kurz warten, lohnt sich!" (klein, optionaler Schmunzler)

## Technik

Szene `programmhinweis`: Typewriter-Einblendung pro Zeichen, Arm-Pointer, Fortschrittsbalken
als gezeichnetes Rechteck.
