# Netzwerk-Erkennung

Damit Client-Apps den VideoWebPlayer im lokalen Netzwerk ohne manuelle Adresseingabe finden, läuft die Server-Erkennung über zwei unabhängige Kanäle: die mDNS-Ankündigung und die UDP-Broadcast-Erkennung. Die Broadcast-Erkennung meldet dabei die öffentliche Basis-URL, unter der der Server für Clients tatsächlich erreichbar ist.
