# Einzelfreischaltungen

## Zweck

Administratoren können einzelne Serien oder Filmsammlungen für ausgewählte andere Anwender freischalten, ohne die gesamte Quelle freizugeben.

## Funktionsweise

1. Ein Administrator öffnet die Detailansicht einer Serie oder Filmsammlung.
2. Neben dem Favoriten-Symbol befindet sich ein Schloss-Symbol:
   - **🔒 Geschlossen:** Das Element ist für keine Anwender freigeschaltet.
   - **🔓 Offen:** Das Element ist für mindestens einen Anwender freigeschaltet.
3. Ein Klick auf das Symbol öffnet einen Dialog mit allen Anwendern.
4. Der Administrator setzt Häkchen bei den Anwendern, die den Titel sehen dürfen, und speichert.

## Sichtbarkeit freigeschalteter Inhalte

Freigeschaltete Serien oder Filmsammlungen erscheinen nur für die ausgewählten Anwender:

- in der Liste **Neu im Programm** auf der Startseite,
- in der Quellen-Auflistung,
- im Menüpunkt der zugehörigen Quelle.

Wenn die Quelle selbst nicht für den Anwender freigegeben ist, werden in der Quellen-Auflistung ausschließlich die explizit freigeschalteten Titel angezeigt.

## Voraussetzungen

- Nur Benutzer mit Administrator-Rolle sehen und nutzen das Freischalt-Symbol.
