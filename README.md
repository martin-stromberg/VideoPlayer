## Key Features

* Registering of media sources
  - FTP
* Scanning sources
  - Video files will be collected in an sqlite database file
  - information of nfo-files with the same name as a found video file will be collected.
  - picture files with the same name as a found video file will be collected.
  - picture files named as folder.png will be collected
* Media Categorization
  - Videos with media information will be categorized in
    - movies and movie colections
    - tv shows with seasons and episodes
  - Collected pictures will be assigned to movies, movie collections, tv shows, seasons or episodes
* Library navigation
  - The user can navigate throw categorized movies and tv shows.
  - Assigned pictures will be displayed.
* Video playback
* Playback history
  - Incompletely watched videos can be continued.
  - movie collection or tv show continuation
* Dark/Light mode
* Cross platform
  - Windows, iOS ready.

## How To Use

To clone and run this application, you'll need [Git](https://git-scm.com) From your command line:

```bash
# Clone this repository
$ git clone https://github.com/Muesli84/VideoPlayer.git

# Go into the repository
$ cd videoplayer

# Open the visual studio solution
$ VideoPlayer.sln
```
