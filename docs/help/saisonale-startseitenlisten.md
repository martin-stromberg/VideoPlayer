# Saisonale Startseitenlisten

Auf der Startseite erscheinen saisonale Genre-Listen, wenn der Server das
Genre aktuell als aktiv führt und passende Medien für dein Benutzerkonto
verfügbar sind. Die Saisonzeiträume werden zentral auf dem Server gepflegt.

Die Listen enthalten Filme, Filmsammlungen und Serien. Sammlungen mit genau
einem Film werden als Filmkarte gezeigt. Leere Genres werden nicht angezeigt.
Mit einem Klick auf eine Karte öffnest du wie gewohnt die passende
Detailansicht.

Die Sektionen enden zum serverseitig berechneten Saisonende. Eine noch offene
Startseite entfernt abgelaufene Sektionen automatisch. Im gemeinsamen Vertrag
für Web und mobile App ist diese Ablaufgrenze als UTC-Zeitpunkt festgelegt.

Die technische Beschreibung steht in der
[API-Dokumentation zu saisonalen Startseitenlisten](../api/seasonal-genres.md).
