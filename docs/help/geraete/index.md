# Geräte

Verwaltung gekoppelter Client-Geräte: Administratoren erzeugen kurzlebige Einmal-Pairing-Codes, mit denen sich Client-Apps (z. B. die TV-App) ein individuelles, widerrufbares Geräte-Token abholen.
