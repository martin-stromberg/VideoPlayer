# Weiterschauen

Verwaltet die Übersicht von Filmen und Serien, die der Benutzer kürzlich angesehen hat, und ermöglicht nahtlose Fortsetzung beim nächsten Aufruf. Das Feature merkt sich Position und Dauer, berechnet die nächste Episode korrekt und zeigt die zuletzt angesehenen Inhalte in übergeordneten Bereichen wie der Startseite.
